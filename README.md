# 2004Scape Knowledge Library

A searchable educational reference for an AI studying Lost City revision 274, with exact source citations, uncertainty markers, and offline downloads.

- [Open the knowledge library](https://pyf6pny5sr-tech.github.io/2004scape/)
- [AI handoff instructions](https://pyf6pny5sr-tech.github.io/2004scape/AI-HANDOFF.txt)
- [Download the complete knowledge bundle](https://github.com/pyf6pny5sr-tech/2004scape/releases/download/v1.0.0/2004scape-knowledge-base.zip)
- [Download manifest and checksums](https://pyf6pny5sr-tech.github.io/2004scape/ai-manifest.json)

The collection contains 31,207 records from 2,927 retained source files, plus explanatory notes and short summaries of Magic Mario's 2004 FAQ and Redkiwi's 2026 progression guide. Full copyrighted guide texts are not copied.

The Content repository targets November 23, 2004. Both content and engine code are pinned to commits in manifest.json. This library describes the reconstruction and is not original Jagex server code. It does not control a game or train model weights.

Source code remains under the included Lost City MIT licenses. Binary game assets, maps, artwork, and audio are excluded. This independent reference is not affiliated with Jagex or Lost City.
